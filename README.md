## Course: APPM 4600

## Overview
This repository contains my homework assignments, labs, and project work for the **Numerical Methods and Applications** course at CU Boulder.  

The course provided an introduction to **numerical analysis** and **scientific computing**, blending mathematical foundations with hands-on coding practice. Weekly group labs, regular assignments, and a final project reinforced both the theory and practical implementation of core algorithms.

---

## Course Topics
### Numerical Analysis
- **Root Finding:** Newton’s method, bisection, fixed-point iteration  
- **Interpolation:** Polynomial interpolation, spline methods  
- **Quadrature:** Numerical integration (trapezoidal rule, Simpson’s rule, Gaussian quadrature)  
- **Linear Systems:** Gaussian elimination, LU factorization, iterative solvers  
- **Eigenvalue Problems:** Power method, approximating dominant eigenvalues  

### Scientific Computing
- **Code Development:** Writing clean, modular Python/C++ code for scientific problems  
- **Repository Management:** Using Git/GitHub for version control and collaboration  
- **Parallel Computing:** Introduction to shared and distributed memory approaches
